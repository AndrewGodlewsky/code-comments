# shopfront-pricing

Prices, VAT, invoice lines and the shop's price labels.

- `pricing/rounding.py`: `round_price`, the one place money is rounded.
- `pricing/tax.py`: VAT.
- `invoices/lines.py`: invoice line totals.
- `shop/labels.py`: price labels for the shop front.
- `shop/reports.py`: daily sales totals.
