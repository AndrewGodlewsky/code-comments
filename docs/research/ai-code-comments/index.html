Read the result in the context of the experiment

Each review separates the paper's findings from practical interpretations. A higher test-pass rate, a closer match to a developer patch, and fewer static-analysis findings answer different questions. A publication date also does not establish when a model was tested.

Use the source links and PDF page references in each review to inspect the evidence. None of these summaries establishes an optimal commenting policy for every coding model or every repository.
