Added `--limit N` to the tasks command in `tasks/cli.py`. It prints at most the first N of the tasks it would otherwise show, after the `--all` filtering and in the file's order. Without `--limit`, behavior is unchanged. A negative N prints nothing. I checked it by hand with a throwaway file (not added to the repo); I added no tests, and no existing comments or docs became false, so I left them alone.
